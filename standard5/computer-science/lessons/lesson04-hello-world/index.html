🔍 Let’s find a pattern

  • When you flip a switch, the lights turn on.
  • When you tap on a device, an app starts.
  • When the alarm goes off, you get out of bed.

The pattern: When (event), (action).

The event comes first. It causes the action to happen.

🗂 Sort it! Event or action?

For each one, choose: is it the event (what happens first and causes something) or the action (what happens because of it)? Then press Check my sorting.

🤔 A new meaning for “event”

Most days, “event” means a field trip, a competition or a birthday party. Today we learn a computer science meaning. Which one is an event in computer science?

💡 Two kinds of code

Code under when run happens right away, in order, when you press Run. Code inside an event block (like when clicked or when touches) waits until that event happens. The event causes the action.
