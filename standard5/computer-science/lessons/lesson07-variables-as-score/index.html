📦 Variable

Stores information (data). The value can change while the program runs.

❓ Condition

Something a program checks to see whether it is true before it takes an action.

🚦 Conditional

A chunk of code that only runs if the condition is true.

Part 3 · Keeping Score with a Variable

📦 A variable is like a box with a label

The label is the name, like score. The box holds information, like the number 0. The information inside the box can change while the game is played.

  1. Show the variable. show variable score at 📍 puts the name and the value on the screen.
  2. Set the variable. set score to 0 gives the starting value.
  3. Change the variable. change score by 1 adds to the value. A negative number, like -1, takes away.
  4. Check the value. if score = 5 checks if the condition is true. If it is true, it runs the code inside.
